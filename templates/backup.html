Baixe uma cópia dos alunos, outreaches e metas para guardar em local seguro.

Como restaurar

Pare o sistema. Na pasta data, renomeie outreaches.db para guardar a versão atual. Copie o backup para essa pasta, renomeie a cópia para outreaches.db e inicie o sistema novamente.

Restaurar uma cópia substitui os dados em uso pelos dados que existiam quando ela foi criada. Guarde os arquivos de backup em local protegido.
